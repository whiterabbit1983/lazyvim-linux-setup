# Результат проверки

Проверка выполнена в отдельном Docker-контейнере **Ubuntu 24.04, x86_64**, от пользователя `tester` с `sudo`. Установка не запускалась на рабочей macOS-машине.

## Успешно

- `bash -n install.sh` и `bash -n tests/smoke.sh`.
- `shellcheck install.sh tests/smoke.sh`.
- `--help`, отказ при запуске от root, отказ при неизвестном параметре.
- Первичная установка всего набора.
- Повторная установка финальной версии скрипта: код завершения `0`.
- Резервное копирование всех 4 каталогов Neovim: контрольные файлы сохранились.
- Повторный запуск не дублирует строки загрузки PATH в `.bashrc` и `.zshrc`.
- Установка всех 14 явно перечисленных Mason-пакетов.
- Rust: `cargo check`, `cargo fmt --check`, `cargo clippy`.
- Go: `go build ./...`.
- Python: создание `.venv`, `py_compile`, `ruff check`.
- TypeScript: компиляция через локальный `npx tsc`, выполнение результата через Node.js.
- C и C++: компиляция и выполнение минимальных программ.
- Инициализация и подключение LSP-клиентов к буферам Neovim: `rust-analyzer`, `gopls`, `basedpyright`, `ruff`, `vtsls`.
- Весь `tests/smoke.sh`: код завершения `0`.

## Не проверено

- Fedora, Arch, отдельная установка Debian, aarch64.
- Интерактивный интерфейс, шрифты, X11/Wayland clipboard, Zsh-сессия.
- Работа отладчика, все операции LSP и все форматтеры.
- Интеграция ESLint с реальным проектом и полное завершение загрузки каждого Tree-sitter-парсера. Парсеры могут доустанавливаться при первом открытии редактора.
- Полный аудит безопасности всех upstream-пакетов.

## Предупреждение npm audit

Во время проверки `npm audit --omit=dev` для Mason-пакета `eslint-lsp` сообщил **3 high-уведомления в одной цепочке зависимостей**:

`vscode-langservers-extracted` → `vscode-markdown-languageservice` → `picomatch`.

Основной advisory: [GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf), ReDoS в `picomatch`. Это сообщение об upstream-зависимости, а не доказательство эксплуатации через данную конфигурацию. Достижимость уязвимости из ESLint LSP не проверялась. Другие инструменты на базе того же пакета, включая JSON LSP, также требуют внимания.

Автоматический `npm audit fix --force` **не запускался**: npm предлагает несовместимую замену версии пакета. Скрипт не скрывает вывод npm и не изменяет вручную зависимости, которыми управляет Mason. Следите за upstream-обновлениями; не считайте успешный smoke-тест аудитом безопасности.

Для `vtsls` и `prettier` тот же npm-аудит не сообщил известных уязвимостей на момент проверки.
